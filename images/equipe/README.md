## Notes

- **Format recommandé** : JPG, portrait, minimum 800 × 1000 px
- **Cadrage** : le site applique `object-position: top` — le visage restera bien positionné même si la photo est plus haute que large
- **Si un fichier est manquant** : le site affiche automatiquement les initiales de la personne (ex. « PB ») sur fond graphite avec halo orange — aucune image cassée
- Après avoir déposé les photos, lancez `npm run deploy` pour publier
